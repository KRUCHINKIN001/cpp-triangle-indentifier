# Определитель треугольника (C++)

Консольная программа, которая записывает длины трех сторон треугольника в бинарный файл, а затем считывает их и определяет, является ли треугольник прямоугольным.

## Описание алгоритма

1. **Запись в файл:** Длины трех сторон (тип `double`) записываются в бинарный файл `sides.bin` с помощью метода `write()`.
2. **Чтение из файла:** Программа открывает файл в режиме `ios::binary` и считывает ровно 3 числа с помощью метода `read()`.
3. **Сортировка:** Полученные стороны сортируются по возрастанию, чтобы самая длинная сторона (гипотенуза, если треугольник прямоугольный) оказалась в конце.
4. **Проверка существования:** Проверяется неравенство треугольника. Если сумма двух меньших сторон меньше или равна большей стороне, треугольник не существует.
5. **Проверка на прямоугольность:** Применяется теорема Пифагора: \(c^2 = a^2 + b^2\). Из-за особенностей хранения чисел с плавающей точкой (`double`) сравнение делается с небольшой погрешностью (`1e-9`).

## Как проверить

1. Выбери пункт 1, введи стороны египетского треугольника: `3`, `4`, `5`. Программа запишет их в файл.
2. Выбери пункт 2. Программа прочитает файл и выведет, что треугольник прямоугольный.
3. Попробуй ввести `3`, `4`, `6` — программа скажет, что треугольник не прямоугольный (или что его вообще нельзя построить).
